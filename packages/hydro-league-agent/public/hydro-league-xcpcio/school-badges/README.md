# School Badge Assets

The contest organizer provided the badge files in this directory solely for
organization identification. Ownership and trademark rights remain with the
respective schools. These badge files are not licensed under the AGPL.

Each deployer must ensure it has authorization to use the badges. The badges
may be replaced or removed for a deployment.

For each original PNG/JPEG badge, the adjacent `.56x56.png` and `.160x160.png`
files are organizer-generated derivatives used by Contest API and CDP exports.
